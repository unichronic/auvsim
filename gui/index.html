What is simulated here?

Each sensor can use a deterministic behavior model or a recorded CSV/TXT trace. Your program source is shown and contract-checked, then the selected algorithm drives a configurable DDS → R-2R → reconstruction filter → output probe model.

Recorded traces accept one normalised value per line or a time,value CSV. Values are resampled at the hardware clock and limited to ±1.5.

Compiler, FPGA synthesis, SPICE, and physical sensor calibration remain separate verification steps.
