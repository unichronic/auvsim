What is simulated here?

The sensor stage generates deterministic noisy sine streams. Your software adapter is contract-checked, then the selected algorithm drives a configurable DDS → R-2R → reconstruction filter → output probe model.

Compiler, FPGA synthesis, SPICE, and physical sensor behaviour remain separate verification steps.
